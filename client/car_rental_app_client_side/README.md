# Car Rental Application

A Flutter-based Car Rental Application developed as a Final Year Engineering Project.

## Tech Stack

- Flutter
- Dart
- Material 3
- Riverpod
- GoRouter

## Features

- Customer Module
- Owner Dashboard
- Car Listings
- Booking Management
- Responsive UI
- Mock Data Integration

## Project Structure

```text
lib/
├── core/
├── shared/
├── features/
│   ├── auth/
│   ├── customer/
│   └── owner/
├── app.dart
└── main.dart
```

## Getting Started

```bash
flutter pub get
flutter run
```
