# Reusable UI Components Catalog

This catalog outlines the customized UI elements built for consistent, premium aesthetics across the Booking Module.

## Layout Elements

* **AppScaffold**: Premium scaffold enforcing correct margins, transitions, and layout wrappers.
* **AppHeader**: Back navigation title bar with support links.
* **SectionContainer**: Large card-like styling with a 16px corner radius and smooth animations.

## Interactive Selectors

* **CustomDatePicker / CustomTimePicker**: Premium modal bottom-sheets using custom grids instead of standard browser-like picker templates.
* **PrimaryButton / SecondaryButton**: High-contrast, tactile response buttons incorporating micro-animations and loading spinners.
* **BookingProgressTimeline**: Horizontal progress tracking header displaying the 5 stages of checkouts:
  `Vehicle -> Pickup -> Extras -> Payment -> Confirmed`

## Specialized Info Cards

* **VehicleBookingCard**: Shows images and technical specs (fuel, automatic/manual, seating configuration).
* **DriverCard**: Displays rating badges, experience years, verified verification indicator, spoken languages, and daily rate.
* **ServiceCard**: Horizontal toggle item with custom check animations showing additional rental addons.
* **CouponCard**: Click-to-apply card outlining active promo incentives.
* **PriceCard**: Expandable calculator details item with interactive breakdowns of fees and deposits.
